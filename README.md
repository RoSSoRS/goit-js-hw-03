# goit-js-hw-03

Домашнє завдання №3 з JavaScript.

- `js/task-1.js` — функція `slugify(title)`, що перетворює заголовок на slug.
- `js/task-2.js` — функція `makeArray(firstArray, secondArray, maxLength)`, що об’єднує масиви та обмежує довжину результату.
- `js/task-3.js` — функція `filterArray(numbers, value)`, що за допомогою циклу та `if` відбирає числа, більші за порогове значення.

## Перевірка

Відкрийте `index.html` у браузері та відкрийте консоль інструментів розробника (F12 → Console).
У ній відображаються результати всіх 15 викликів із завдання.

Файли JavaScript також можна виконати окремо через Node.js:

```sh
node js/task-1.js
node js/task-2.js
node js/task-3.js
```

Налаштування форматування збережені у `.prettierrc`.
